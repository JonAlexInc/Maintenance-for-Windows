# Security policy

0.01 is an early preview, not a production-supported release. A support schedule has not been established.

Do not post exploit details, private paths, client data, or raw logs in public issues. GitHub private vulnerability reporting is enabled for this repository. Use [Report a vulnerability](https://github.com/JonAlexInc/Maintenance-for-Windows/security/advisories/new) to submit a private report to the maintainer. GitHub sign-in may be required. No response-time guarantee or production support schedule is established.

Security-relevant areas include path traversal/redirection, file identity races, exclusions, unintended elevation, local records, and report privacy. Reports should describe the affected version, expected behavior, actual behavior, and a reproduction using synthetic files.
