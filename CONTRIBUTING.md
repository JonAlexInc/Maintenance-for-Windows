# Contributing

This project is a public consumer preview with free personal use and reserved source-reuse rights; see LICENSE. External code contributions are not yet accepted while contributor terms are being established. The future commercial Technician edition is separate.

Use issues for non-sensitive bugs and feature discussions. Never include real client records, credentials, license material or unredacted activity journals.

For development, use Windows 11 x64 and a .NET 8 SDK. Build the app and run the fixture tests using the README commands. Keep cleanup scope narrow; safety checks must fail closed. All cleanup tests must use disposable generated fixtures, never the developer's actual temporary files. Update the scope documentation when behavior changes.

Report security vulnerabilities privately using SECURITY.md, not a public issue.
