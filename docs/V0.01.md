# Version 0.01 scope

Approved implementation direction: October 10, 2026. Display version: 0.01 Preview. Package/release version: 0.0.1 / v0.0.1.

## Included

1. Read-only computer overview and collection time.
2. Default current-user temporary-folder scan with conservative seven-day creation/write cutoff.
3. Review of eligible paths, logical sizes, last-write times, and skipped items.
4. Explicit selection, permanent-deletion confirmation defaulting to Cancel, progress and cancellation.
5. File/folder exclusions retained across launches and honored at execution.
6. Results and newest 30 local activity journals with interruption-aware pending entries.
7. Free expandable expert details.
8. Plain-text support export with preview and optional identifying paths.

## Acceptance evidence required

- Build without errors or warnings.
- Fixture-based tests cover boundaries, replaced/changed/locked files, exclusions, junctions, hard links, cancellation, journal failures, and report redaction.
- UI opens and renders all screens.
- Human acceptance on a disposable Windows 11 machine: scan, choose files, confirm, cancel partway, inspect partial failures, restart, verify exclusions/history, export both redacted and identified reports.
- Representative everyday users understand what will be deleted and that deletion is permanent before confirmation.

Automated tests and a UI smoke check do not establish human comprehension or production readiness. Do not perform acceptance cleanup on valuable user files.

## Deferred

Startup controls, cross-scan change comparison, installer/signing/updater, technician sessions/licensing/PDFs, Guided Care, repair automation, malware/rootkit detection, other platforms. See ROADMAP.md for exact-duplicate detection and richer application ownership/remnant analysis.

## Known preview limits

- Temporary cleanup uses explicit source checkboxes. Browser cleanup uses supported current-account cache layouts; portable/custom profiles and unsupported browsers are not assumed safe.
- The seven-day rule is conservative but not a guarantee that old temporary data is unused.
- One Scan action with optional Max wait (seconds), otherwise completion/manual cancellation; a partial scan can still be reviewed and cleaned.
- The history view uses timestamped activity IDs. Scan histories retain summaries, not full lists of inspected files.
- Plain Windows Forms controls are an initial functional interface, not an accepted final visual design.
- Current demo is a self-contained, single EXE for Windows 11 x64; bundled content extracts to the current account's temporary area. Public-release signing and runtime servicing remain outstanding.

## Expanded review modes

- System Restore: list creation dates/descriptions/types; protect newest point; revalidate identity before native SRRemoveRestorePoint; verify absence before reporting success; permanent removal with explicit confirmation. Shared VSS usage is not an individual restore-point size or guaranteed reclaim estimate.
- Update/installation storage: bounded, cancellable read-only folder measurements, rollback/staging warnings, and Windows cleanup/settings links. Installer and component-store data are reference-only; never directly deleted by this mode.
- Virtual machines: local/removable drives, supported disk/snapshot/configuration/export formats, sortable sizes and paths, search and CSV export. Read-only; no ownership/dependency claims. Ambiguous raw/img formats require opt-in.
- App data: conservative two-level current-account Local AppData cache/log review, user/machine uninstall evidence, uncertain ownership explicitly retained, installed-app usage unknown. Individual reviewed files can be recycled through the existing personal-file flow. No whole app-folder deletion or automatic uninstall.
- ADS viewer: read-only 64 KiB maximum preview, text/hex, Zone.Identifier origin fields shown as untrusted plain text.
- Settings: monitor inches/centimeters and appearance; Windows inventory adds release/build/install date/activation/update-policy/channel details and live uptime.
